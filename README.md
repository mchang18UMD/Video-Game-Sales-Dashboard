## Project Overview

The Video Game Sales Dashboard allows users to explore historical video game sales data. Users can search for video games, filter information, compare regional sales, and explore sales data through visualizations.

## Dataset

- Dataset Name: Video Game Sales
- Source: [Kaggle](https://www.kaggle.com/datasets/gregorut/videogamesales)
- Number of Records: 16,598
- File Format: JSON
- Sales are measured in millions of copies.

## Features

- Search for video games by their titles.
- Display video game rank, name, platform, year, genre, and publisher.
- Filter video games by platform, genre, and release year.
- View video game sales across different regions.
- Display the number of matching search results.
- Visualize historical video game sales data (in progress).

## Website Pages

- **Home:** Introduces the purpose of the web application and provides an overview of the dataset.
- **Search:** Allows users to search for video games and provides filter options.
- **Graph:** Displays video game sales data through charts (in progress).
- **About:** Provides details about the dataset and how it is used in the dashboard.
